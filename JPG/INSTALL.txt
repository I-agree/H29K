============================================
  开机动画 + 双页信息屏（全合一）
============================================

文件:
  drm_play_arm64  - 开机动画 + 双页信息屏
  99-bootanim     - OpenWrt init.d 开机脚本

页面:
  第 1 页 = 一言 + 随机背景图（每 15 分钟刷新）
  第 2 页 = 上网模块信息（黑底白字，每 60 秒刷新）
翻页: 右→左 = 下一页；左→右 = 上一页（瞬时跟手）

第 2 页数据源（按真实缓存格式定稿）:
  主路径: 直接读 /tmp/cache_base_info_* / cache_sim_info_* /
          cache_cell_info_* / cache_network_info_*
  字段:  connect_status / temperature / SIM Status / ISP /
         network_mode / UL Bandwidth / DL Bandwidth
  清洗:  去首尾换行、掳C→°C、Yes→已连接、No→未连接、ready→就绪
  兜底:  ubus 探测 + /var/run/qmodem（七项不齐时才走）

安装:
  scp drm_play_arm64 root@192.168.1.1:/usr/sbin/
  scp 99-bootanim root@192.168.1.1:/etc/init.d/
  scp MiSans-Regular.ttf root@192.168.1.1:/usr/share/fonts/
  ssh root@192.168.1.1
  chmod +x /usr/sbin/drm_play_arm64 /etc/init.d/99-bootanim
  /etc/init.d/99-bootanim enable

排查（如有项显示 --）:
  cat /tmp/.qmodem_dbg_all

触摸方向修正（实测正确，通常无需）:
  横滑无反应竖滑才翻 → 编译行加 -DTOUCH_SWAP
  能翻但方向反     → 编译行加 -DTOUCH_INVERT

停止: killall drm_play_arm64
