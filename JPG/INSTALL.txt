============================================
  开机动画 + 四页信息屏（全合一）
  HINLINK H29K / RK3528 / GC9307 320x172
============================================

文件:
  drm_play_arm64    - 开机动画 + 四页信息屏（ARM64 静态编译）
  99-bootanim       - OpenWrt init.d 开机脚本
  drm_ui_logic.h    - 纯逻辑头文件（亮度曲线/翻页/手势），仅供编译与单元测试
  INSTALL.txt       - 本文件

--------------------------------------------
页面（共 4 页，上下滑动循环翻页）
--------------------------------------------
  第 1 页  一言 + 随机背景图      每 15 分钟刷新
  第 2 页  上网模块信息（黑底白字）每 60 秒刷新
  第 3 页  亮度调节               拖动滑块，实时生效，松手自动保存
  第 4 页  设备                   按住滑块拖到最右 → 重启设备

  翻页手势：上滑 = 上一页，下滑 = 下一页，末页与首页相连循环
  左右滑动：一律无效（亮度改为拖动滑块精调，避免误触）
  自动回首页：停留在非首页且完全静止 2 分钟 → 自动跳回第 1 页

--------------------------------------------
亮度控制（硬件调光，真省电）
--------------------------------------------
  设备    /sys/class/backlight/pinctrl:backlight   (pwm-backlight, pwm6, 40kHz)
  量程    0 .. 255，DTS brightness-levels 为恒等线性
  曲线    UI 百分比 -> level 采用 gamma 2.2 + 10% 线性混合
          0%->16  25%->32  50%->75  75%->148  100%->255
          level 150 = UI 75%，level 200 = UI 88%
  下限    level 16（BL_MIN_LEVEL）。滑块拉到底也不会全黑，
          避免用户误以为死机；level 0 只保留给息屏逻辑。
  默认    level 150（实测 DTS 默认的 200 偏亮）
  配置    /etc/config/drm_play_arm64   UCI 格式（兼容 key=value）
          仅在拖动松手时写入一次，tmp+rename 原子替换，不磨损 flash

  ★ 只写 brightness，不碰 bl_power ★
  DTS 中面板节点带 backlight = <&backlight>，bl_power 由内核面板驱动
  独占（进程退出关 CRTC 时驱动会自动写 bl_power=4）。用户态若同时写
  bl_power 会与驱动互相覆盖，故本程序全程只操作 brightness。

--------------------------------------------
省电息屏（真断电，非假黑屏）
--------------------------------------------
  触发    无有线/无线客户端持续 60 秒
  动作    ① 背光 level 写 0（DTS 极性反转 → PWM duty 0 → LED 电流为 0）
          ② 再把全黑帧刷进 GRAM（面板供电常开，GRAM 保留内容，
             万一背光被意外点亮也只会看到纯黑）
  唤醒    触摸或客户端回归
          ① 背光保持 0（推送过程不可见）
          ② 重绘目标页面并推送
          ③ 最后恢复用户亮度 → 全程绝无白闪
  顺序    唤醒时若距最后一次触摸已超过 2 分钟，直接回第 1 页，
          不会回到息屏前的页面（避免半夜摸屏落在重启页）

  客户端检测（每 20 秒）
    有线 5 重兜底: eth0/carrier → operstate → speed → br-lan/brif → ethtool
    无线: ubus → hostapd_cli / iw / iwinfo

--------------------------------------------
第 4 页重启（防误触）
--------------------------------------------
  必须按住滑块横向拖动到 90% 以上再松手才会重启。
  拖动中滑条变红并显示已拖动百分比，未到位松手则弹回取消。
  触发后显示"正在重启设备"，sync() 后 execl /sbin/reboot，
  10 秒未成功则用 reboot(RB_AUTOBOOT) 内核兜底。

--------------------------------------------
安装
--------------------------------------------
  scp drm_play_arm64 root@192.168.1.1:/usr/sbin/
  scp 99-bootanim    root@192.168.1.1:/etc/init.d/
  scp MiSans-Regular.ttf root@192.168.1.1:/usr/share/fonts/
  ssh root@192.168.1.1
  chmod +x /usr/sbin/drm_play_arm64 /etc/init.d/99-bootanim
  /etc/init.d/99-bootanim enable
  /etc/init.d/99-bootanim start

  停止: /etc/init.d/99-bootanim stop   （或 killall drm_play_arm64）

--------------------------------------------
排查
--------------------------------------------
  运行日志    cat /tmp/drm_play.log
              启动时会记录背光节点/量程/生效 level、触摸设备与 ABS 量程映射，
              退出时记录"抬手兜底次数/事件队列溢出次数"。
  亮度配置    cat /etc/config/drm_play_arm64
  手动调光    echo 120 > /sys/class/backlight/pinctrl:backlight/brightness
  实时背光    cat /sys/kernel/debug/pwm | grep -A2 backlight

  若发现"手指按住不动，滑块自己松开了"：
  说明该触摸驱动不持续上报坐标，把源码里的 TOUCH_IDLE_MS 从 500 调大
  （例如 2000）后重新编译即可。日志里的"抬手兜底次数"可用来确认。

  若滑块上下方向与实际相反：调整源码 SWIPE 方向映射（uil_swipe_pages
  的返回值符号），或在编译时加 -DTOUCH_INVERT 风格的开关。

--------------------------------------------
本次构建自带单元测试（workflow 内自动执行）
--------------------------------------------
  test_logic.c  63 项断言：亮度曲线端点/单调性/往返一致性/无死区、
                循环翻页、垂直手势判定、滑块与重启滑条换算
